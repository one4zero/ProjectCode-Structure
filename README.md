ProjectCode&Structure GUI
Утилита для визуального отображения структуры проекта и копирования содержимого всех файлов. Упрощает ввод чат-бота в контекст кода, архитектуры и задач проекта.
Установка зависимостей:
```
pip install tk
```

Запуск:
```
python project_viewer.py
```

Функции:
- Выбор директории
- Отображение структуры всех папок и файлов (без изображений)
- Вывод содержимого всех файлов проекта
- Копирование текста одним кликом
- Сохранение результата в .txt файл

Требования:
- Python 3.6 или выше
Форматы изображений автоматически исключаются из вывода: .jpg, .jpeg, .png, .gif, .bmp, .tiff, .ico, .webp
